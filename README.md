# Address Book Management System

## Project Overview
The Address Book Management System is a console-based application developed using C programming. It allows users to manage contact information through a simple menu-driven interface.

## Features
- Add new contacts
- View saved contacts
- Search for contacts
- Edit existing contacts
- Delete contacts
- Store and manage contact information using file handling

## Technologies Used
- C Programming
- File Handling
- Visual Studio Code
- Git
- GitHub

## Project Files
- `main.c` - Main program
- `menu.c` - Menu display and navigation
- `fileops.c` - File operations
- `log.c` - Logging functions
- `abk.h` - Header file containing declarations and structures

## How to Run
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Compile the C source files using a compatible C compiler.
4. Run the generated executable.
